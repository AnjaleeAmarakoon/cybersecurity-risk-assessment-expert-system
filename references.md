# Authoritative Knowledge Sources

Accessed: 29 September 2026.

## S1 - CISA: Secure Our World
https://www.cisa.gov/secure-our-world

Use in system: CISA identifies four foundational habits: recognize/report phishing, use strong passwords, enable MFA, and update software.

## S2 - CISA: Turn On MFA
https://www.cisa.gov/secure-our-world/turn-mfa

Use in system: Enable MFA on every account or app that offers it; MFA adds protection even when a password is stolen.

## S3 - CISA: Secure Our World - Software Updates Tip Sheet
https://www.cisa.gov/sites/default/files/2024-09/Secure-Our-World-Software-Updates-Tip-Sheet.pdf

Use in system: Turn on automatic updates, install updates promptly, and keep browsers and antivirus software current.

## S4 - CISA: Secure Our World - Four Easy Ways to Stay Safe Online (Audio Description)
https://www.cisa.gov/sites/default/files/2023-09/SOW-Web-Page-Animation-Four-Easy-Ways-Audio-Description.pdf

Use in system: Use long, random and unique passwords; recognize/report phishing; do not click suspicious links; update software.

## S5 - NIST: How Do I Create a Good Password?
https://www.nist.gov/cybersecurity-and-privacy/how-do-i-create-good-password

Use in system: NIST recommends MFA, unique passwords, password managers and long passwords; reused passwords create cross-account risk.

## S6 - NIST: Cybersecurity Basics
https://www.nist.gov/itl/smallbusinesscyber/cybersecurity-basics

Use in system: Enable MFA, use strong passwords/password managers, back up data, change default passwords, maintain antivirus, and patch software.

## S7 - CISA: How to Protect the Data that is Stored on Your Devices
https://www.cisa.gov/resources-tools/training/how-protect-data-stored-your-devices

Use in system: Back up data, encrypt devices/media/files, protect recovery keys, disconnect backup drives when not in use, and use standard accounts for daily activity.

## S8 - CISA: Using Wireless Technology Securely
https://www.cisa.gov/sites/default/files/publications/Wireless-Security.pdf

Use in system: Public wireless networks can expose activity; use a VPN and avoid sensitive activities when a secure connection is unavailable.

## S9 - CISA / US-CERT: Home Router Security
https://www.cisa.gov/sites/default/files/publications/HomeRouterSecurity2011.pdf

Use in system: Change default router login credentials because default credentials are widely known and can be abused.

## S10 - CISA: Internet Exposure Reduction Guidance
https://www.cisa.gov/resources-tools/resources/exposure-reduction

Use in system: Change default passwords, apply security patches, replace unsupported software/devices, and use MFA where possible.

## S11 - NIST: NIST SP 800-63B: Authentication and Authenticator Management
https://pages.nist.gov/800-63-4/sp800-63b.html

Use in system: For single-factor passwords NIST requires a minimum of 15 characters and recommends protections against compromised passwords.
